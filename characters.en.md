# Five Percent Quest — English character reference

This file documents all 64 playable/NPC character roles. The original Hungarian characterization, dialogue samples, and longer backstories remain in `actors.js`, which is the authoritative data source. The short summaries below are English role introductions, not full literary translations of the original biographies.
